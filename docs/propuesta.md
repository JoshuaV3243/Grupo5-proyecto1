# Propuesta: Sistema de ventas en tienda

## Nombre
Sistema de ventas en tienda.

## Integrantes
- Integrante 1: pendiente de completar.
- Integrante 2: pendiente de completar.

## Problema
El registro manual de productos y ventas dificulta conocer las existencias y
puede producir errores al sumar importes o entregar el cambio.

## Justificación
Una aplicación de escritorio permite reunir el inventario y la venta en un
flujo sencillo, validar los datos y consultar lo vendido durante una sesión.

## Usuarios
Persona encargada de caja y persona encargada de los productos de la tienda.

## Objetivo general
Desarrollar una aplicación de escritorio que permita administrar productos y
registrar ventas de una tienda mediante C# y Windows Forms.

## Objetivos específicos
- Registrar, buscar, modificar y eliminar productos.
- Controlar los datos obligatorios, los duplicados y las existencias.
- Construir una venta con productos y cantidades, calcular su total y cambio.
- Consultar las ventas registradas y sus detalles por fecha.
- Mantener código comprensible y documentación útil para el trabajo en pareja.

## Alcance
Primera versión funcional para una sola computadora. Productos y ventas se
almacenan en listas durante la ejecución. Se incluyen productos de demostración.

## Fuera de alcance
Base de datos, persistencia al cerrar, usuarios y contraseñas, facturación
electrónica, cálculo fiscal, conexión a bancos, sucursales y uso concurrente.

## Funcionalidades
Menú principal, mantenimiento de productos, carrito, confirmación de venta,
descuento de existencias e historial con detalle y filtro por fechas.

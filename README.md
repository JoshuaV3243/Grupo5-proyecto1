# Sistema de ventas en tienda

Proyecto académico en C# y Windows Forms. Primera versión en construcción.

El objetivo es administrar productos y registrar ventas en una tienda pequeña,
con listas en memoria y una interfaz sencilla para quien atiende la caja.

## Integrantes

- Integrante 1: **pendiente de completar por el equipo**.
- Integrante 2: **pendiente de completar por el equipo**.

## Organización inicial

- `src/SistemaVentasTienda.Core`: modelos, datos y reglas del sistema.
- `src/SistemaVentasTienda.WinForms`: formularios, controles y eventos.
- `tests/SistemaVentasTienda.Pruebas`: comprobaciones de la lógica.
- `docs`: propuesta y documentación técnica en Markdown.

El repositorio local se inicia antes de implementar los módulos. Su historial
registrará las etapas reales de esta preparación. La participación de cada
integrante deberá quedar registrada por ellos en su propio trabajo en GitHub.
